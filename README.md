# Gym Website

A static gym and fitness website built with HTML and CSS, with local image and video assets.

## Tech Stack
- HTML5
- CSS3

## Run Locally
Clone or download the repository and open `index.html` in a browser. No build step is required.

## Project Structure
- `index.html` — website structure and content
- `style.css` — page styling
- `img/` — image assets
- `vid/` — video assets
